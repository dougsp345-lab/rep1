# Validation

Validated on October 29, 2026.

- Node tests cover independent vs assisted evidence, recognition-only limits, all-word coverage, delayed reading, review intervals, resets, import validation, corrupt/blocked storage, and curriculum structure.
- Completion simulations exercised all 120 lessons with adult-checked reading and unavailable device audio, including the deliberately small e_e word bank.
- Browser interaction checks covered the lesson flow, oral checks, spelling correction, contextual heteronym checks, profile creation/switching, reload persistence, and an isolated lesson reset.
- Desktop and 375px embedded mobile viewport were visually inspected.
- The test browser exposed speech synthesis but had no working voice. Audio error recovery was implemented and checked; actual audible voice quality must be verified on the learner's device. Pure phonemes require adult modeling.

The educational content is an original, reviewed implementation of evidence-supported principles. It has not been field-tested or validated as a standardized reading assessment. Advanced context variants are rotated over practice; a progress label is not certification of every possible pronunciation, accent, or exception.
